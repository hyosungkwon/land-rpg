# ⚔️ 영지 RPG — 게스트 전용 통합 부동산 RPG (v6.0.0)

로그인 없이 **바로 시작**하는 모바일 세로형 방치형 RPG + 전국 부동산 게임입니다.
사냥과 부동산이 **골드 하나**로 이어지는 단일 경제로, 별도 환전·이중 연동 없이 한 화면에서 돌아갑니다.

- 라이브: https://hyosungkwon.github.io/land-rpg/
- 저장: `localStorage` (`land_rpg_unified_v3` — v4.8도 같은 키. v4.8의 새 필드는 **`cloud`**(선택적 클라우드 설정: 꺼짐/켜짐·닉네임·60초 자동저장·마지막 동기화) 하나이고, 기존 저장본은 **꺼짐(게스트)** 으로 자동 마이그레이션된다) · 기본은 계정/서버 없음 · 오프라인 동작 (PWA)
- ☁️ **선택적 클라우드**: 설정 탭에서 원할 때만 Google 로그인으로 세이브 백업 + 🏆 랭킹 참여 (안 켜면 예전과 똑같은 게스트)
- 390×844 기준 모바일 레이아웃

### 매물 가격 (골드/평)

원본 korea-land 시세를 RPG 골드 스케일로 압축했습니다 (`land.js`의 `priceScale`, `tierPriceMults`).

| 구분 | 가격대 | 회수(임대) |
|---|---|---|
| 군(郡) | 120 ~ 2,000 | 5.6시간 (18%/h) |
| 시(市) | 1,700 ~ 42,800 | 8.3시간 (12%/h) |
| 구(區) | 7,200 ~ 200,000 (강남 200,000) | 11.9시간 (8.4%/h) |

- 임대수익 = 매물 가치의 분당 0.2%(시간당 12%) × 지역 배율(군 1.5 · 시 1.0 · 구 0.7) → **접속 중 100%, 앱을 닫아둔 동안 25%**(최대 12시간)
  - v3.0.6에서 장기 방치 복리 스노우볼을 늦추기 위해 분당 1% → 0.2%, 오프라인 5% → 25%로 조정했습니다(시간당 실효 2.1~4.5%).
- 거래세 0.3%, 시세는 일일 기준가 ±8% / 장중 ±12% (지역 특성에 따라 확대), 일일 밴드 ±30%
- 한 지역 지분이 커질수록 평당 수익이 줄어드는 원작 규칙 유지

## 5. v3.1 재미 요소 (장비 뽑기 · 타격감 · 효과음)

### 장비 등급 뽑기

강화 레벨(0~100)은 그대로 두고 **등급**을 뽑기로 얻습니다. 장비/강화 탭 상단 카드에서 1회 / 10회 연속.

| 등급 | 확률 | 보정 | 중복 분해 | 오라·검기 색 |
|---|---|---|---|---|
| 일반 | 52% | +0강 | 💎2 | 황금 |
| 고급 | 28% | +4강 | 💎6 | 초록 |
| 레어 | 13% | +9강 | 💎14 | 파랑 |
| 영웅 | 5.5% | +16강 | 💎30 | 보라 |
| 전설 | 1.5% | +25강 | 💎70 | 불타는 적금빛 + 파티클 |

- 가격: 💰600 / 💎10 (1회), 10회는 10% 할인(💰5,400 / 💎90) + **최소 레어 1개 보장**
- **천장**: 40회 안에 전설 1개 확정(전설이 나오면 카운터 초기화)
- 더 높은 등급은 **자동 장착**, 같거나 낮은 등급은 **강화석 자동 분해**(교체된 이전 장비도 분해)
- 등급 보정은 강화 레벨에 더해져 스탯에 반영되고, 발밑 **오라**(5부위 평균 등급)와 **검기 아크**(무기 등급) 색이 바뀝니다.

### 타격감 · 연출 · 효과음

- 몬스터 사망 시 금화·보석이 포물선으로 튀어오른 뒤 0.4초 후 캐릭터로 **자석처럼 빨려 들어오는** 캔버스 연출

## 6. v3.2 재미 요소 (동료 펫 · 전직 · 황금 던전)

### 🐾 부동산 연계 동료 펫

보유 부동산이 자라면 **자동으로 해금**되고, 장착한 펫이 전투 캔버스에서 주인공 뒤를 따라다니며 **1.5초마다 함께 공격**합니다.

| 펫 | 해금 조건 | 함께 공격 | 패시브 |
|---|---|---|---|
| 🐺 꼬마 늑대 | 보유 지역 1곳 | 공격력 55% | 공격력 +3% |
| 🦊 불여우 | 보유 100평 | 공격력 80% | 공격력 +5% · 골드 +4% |
| 🦉 황금 부엉이 | 총자산 5만 골드 | 공격력 70% | 공격력 +4% · 골드 +10% |
| 🐲 아기 드래곤 | 보유 지역 10곳 | 공격력 120% | 공격력 +8% · 골드 +6% |

- 조건을 채우면 토스트로 알리고, 직접 고른 적이 없으면 **가장 높은 펫으로 자동 교체**됩니다(직접 고르면 유지).
- 펫 스프라이트는 `image-generation`으로 만든 256px 투명 PNG(`assets/sprites/pet/`)이고, 피해 숫자·참격·발밑 광휘가 펫 색을 따릅니다.
- **펫 강화(💎)**: Lv.1~10, 1단계마다 함께 공격 피해·공격력 패시브가 +10% (비용 8 → 161 강화석).
- UI: **사냥/스킬 탭**과 **부동산 → 건물주 버프 탭**의 🐾 내 동료 펫 카드에서 해금 조건·진행도·교체·강화.

## 8. v3.4 부동산 전략 (📰 호재 뉴스 · 🗺️ 권역 세트 · 🏛️ 랜드마크)

### 📰 부동산 호재 뉴스 (3분 주기)

부동산 탭 **맨 위 뉴스 배너**에 지금 적용 중인 호재가 뜨고, **3분마다 새 호재**로 바뀝니다(지속 3분).
시세 모델과 같이 **시간 기반 결정론**이라 모든 기기가 같은 순간 같은 뉴스를 봅니다.

- 범위: **권역**(서울권·경기·인천권·강원권·충청권·전라권·경상권·제주권) / **지역 1곳**(강남구·송파구·수원시·해운대구·전주시) / **섹터**(군·시·구 전체)
- 효과: **시세 보정**(예: 반도체 클러스터 착공 → 경기·인천권 시세 +12%) + **임대수익 버프**(예: +50%)
- 적용 지역은 매물 목록·보유 매물에서 **📈 호재 배지 + 금빛 강조**로 한눈에 보이고, 배너에 **남은 시간·진행 바·내 지역 적용 수**가 실시간으로 표시됩니다.
- 내 보유 지역에 호재가 걸리면 토스트로 알려 줍니다.

### 🗺️ 권역 세트 (지역 시너지)

같은 권역 지역을 **일정 수 이상** 보유하면 단계별(Lv.1~3)로 세트 버프가 열립니다. 현황은 **부동산 → 건물주 버프** 탭에서 확인합니다.

| 권역 | 단계 조건 | 세트 버프 |
|---|---|---|
| 🏙️ 서울권 | 3 / 6 / 10곳 | **임대수익 +8 / +16 / +26%** |
| 🏭 경기·인천권 | 3 / 6 / 10곳 | 공격력 +4 / +8 / +14% |
| ⛰️ 강원권 | 2 / 4 / 7곳 | 드롭률 +5 / +10 / +18% |
| 🌾 충청권 | 3 / 6 / 10곳 | 골드 획득 +4 / +8 / +14% |
| 🌿 전라권 | 3 / 6 / 10곳 | 임대수익 +5 / +10 / +18% |
| 🚢 경상권 | 3 / 6 / 12곳 | 공격력 +3 / +6 / +12% |
| 🏝️ 제주권 | 1 / 2곳 | 골드 +3/+7% · 임대수익 +4/+10% |

- 세트 **임대수익**은 그 권역 매물에만, **공격/골드/드롭**은 캐릭터에 영구 적용됩니다(건물주 버프와 **별도 합산**).
- 서울 25 · 경기·인천 41 · 강원 18 · 충청 32 · 전라 41 · 경상 70 · 제주 2 = **229개 지역이 빠짐없이 7개 권역에 매핑**됩니다.

### 🏛️ 랜드마크 건설/업그레이드

**5평 이상** 보유한 지역에 골드를 투자해 **Lv.1 상가 → Lv.2 타워 → Lv.3 메가 랜드마크**를 세웁니다.

| 레벨 | 이름 | 그 지역 임대수익 | 건설 비용 |
|---|---|---|---|
| Lv.1 | 🏬 상가 | **+30%** | 보유평 × 기준가 × 0.35 |
| Lv.2 | 🏢 타워 | **+70%** | 보유평 × 기준가 × 0.9 |
| Lv.3 | 🏙️ 메가 랜드마크 | **+120%** | 보유평 × 기준가 × 2.2 |

- 랜드마크 1개당 건물주 **공격력 +1%**(최대 +15%) · **골드 +0.5%**(최대 +10%)
- 건설은 **내 부동산 → 보유 매물의 🏛️ 랜드마크 버튼**(또는 건물주 버프 탭 목록)에서 하며, 모달에서 단계·비용·효과를 보고 확정합니다.
- 그 지역을 **전량 매도하면 랜드마크도 함께 정리**됩니다(남은 평수가 5평 미만이면 업그레이드만 막힘).

## 12. v3.6 💾 세이브 코드 백업 · 편의성

기기를 바꾸거나 브라우저 데이터를 지워도 진행도를 되살릴 수 있게, 저장 전체를 **코드 한 줄**로
내보내고 복원합니다. 계정·서버는 여전히 없습니다.

### 💾 내보내기 / 불러오기 (설정 탭)

| 단계 | 동작 |
|---|---|
| 📤 내보내기 | 현재 세이브(레벨·골드·장비·부동산·펫·미션·도감·환생)를 `LANDRPG3:` 코드로 만들어 모달에 보여 주고 **📋 복사하기** |
| 📋 복사 실패 시 | `navigator.clipboard` 가 막히면 텍스트 영역 전체 선택 + `execCommand('copy')` 로 폴백, 그것도 안 되면 "길게 눌러 복사" 안내 |
| 📥 불러오기 | 코드를 붙여넣고 **🔍 검증 · 미리보기** → 지금 세이브와 코드를 나란히 비교(레벨·최고 스테이지·보유 지역·환생 + 골드·강화석·장비 총 강화) → **💾 복원** |
| ↩️ 직전 세이브로 복구 | 복원 직전 세이브를 `land_rpg_unified_v3_prev` 에 보관해, 잘못 복원해도 설정 탭에서 되돌릴 수 있습니다 |

**코드 형식**: `LANDRPG3:<base64url(JSON)>.<FNV-1a 32bit 체크섬 8자리>`

- JSON 을 **UTF-8 바이트 → base64url(`-` `_`, 패딩 없음)** 로 인코딩해 한글·이모지도 안전하고, 메신저에서 `+`/`/` 가 깨지지 않습니다.
- 체크섬이 한 글자만 달라져도 **거부**합니다. 형식 오류·잘린 코드·빈 입력·다른 버전(`LANDRPG2:`)·JSON 아님·객체 아님도 모두 사유와 함께 거부하며, **기존 세이브는 그대로** 남습니다.
- 복원 데이터는 항상 `normalizeState` 를 거치므로 음수 레벨·골드, 100강 초과, 미지 등급, 없는 지역 랜드마크 같은 손상 값은 기존 저장과 같은 규칙으로 정리됩니다.
- 코드에는 **시점 값(`lastActiveAt`·`land.rentAt`)과 화면 상태(페이지·정렬·검색·자산 그래프)** 를 담지 않습니다 → 복원 직후 방치 보상이나 밀린 임대수익이 한꺼번에 들어오지 않고, 복원 시점부터 새로 쌓입니다.
- 크기: 중반 세이브 약 2KB, 전 지역 보유·엔드게임 세이브 약 13KB(모달에 글자 수·KB 표시).

### ⚡ 편의성 — 터치 수 줄이기

- **장비 일괄 강화**: 각 부위 버튼이 `+1 💎비용` · `+5` · `+10` · `최대 +N` 4개로 넓어졌습니다. `최대`는 지금 강화석으로 올릴 수 있는 횟수(N)를 보여 주고 한 번에 올립니다. 강화석이 모자라면 **가능한 만큼만** 오르고 토스트에 `+3강 · 강화석 소진` 처럼 표시됩니다.
- **부동산 빠른 매수**: 매수 모달의 수량 버튼이 `1 · 10 · 50 · 100 · 1000 · 최대 N평` 으로 보완되어, 큰 금액을 한 번에 집행할 때 입력 없이 누르면 됩니다(견적·거래세·거래 후 골드는 그대로 미리보기).
- **임대수익 일괄 수령**: 부동산 홈 카드에서 **한 번** 누르면 보유한 모든 매물의 임대수익이 한꺼번에 들어옵니다(모달 없음). `내역` 을 누르면 지역별 시간당 임대 상위·하루 임대·누적 수령을 보여 주고 거기서도 `모두 수령` 할 수 있습니다.
- 사냥 탭의 `수령` 버튼도 같은 원탭 수령을 씁니다.

### 저장 호환

`localStorage` 키는 그대로 `land_rpg_unified_v3` 이고, 새 키는 백업용 `land_rpg_unified_v3_prev` 하나뿐입니다.
v3.1~v3.5 진행도(미션·업적·도감·부동산·펫·전직·환생)는 손실 없이 이어지고, 복원 후에는 전투·렌더러·UI 가 새 세이브로 다시 연결됩니다(실패하면 새로고침으로 안전하게 복구).

- 손상된 `cloud` 값(문자 `enabled`, 음수 `lastSync`, 12자 초과 닉네임)은 정리됩니다.
- PWA 캐시는 `land-rpg-v4.8.0` 으로 갱신(`src/cloud.js` 프리캐시, Firebase CDN 은 캐시하지 않음) — v4.8.0 기준.

## 25. 알려진 한계

- 계정/클라우드 저장은 **선택 사항**입니다 — 켜지 않으면 예전과 같은 게스트 전용이라 브라우저 데이터를 지우면 진행도가 사라집니다. v3.6부터는 **세이브 코드**로 직접 백업·복원할 수 있습니다 — 코드를 잃으면 되살릴 수 없으니 메모·메일에 보관하세요.
- v3.5부터 스테이지 상한은 없지만(S31 이후 ∞), S100 부근은 환생을 여러 번 반복해야 뚫리는 장기 목표입니다. v3.4까지의 성장 한계(S29 부근에서 장비 100강·버프 상한)는 첫 회차 기준이며, 환생 특성이 이 벽을 넘는 수단입니다.
- v4.8 랭킹은 **클라이언트가 보낸 값**을 그대로 보여 줍니다(Spark 요금제 · Cloud Functions 없음). 조작을 막는 서버 검증은 없으므로 기록은 참고용입니다.
- 클라우드 세이브는 로그인 계정 하나에 한 벌입니다. 같은 계정으로 두 기기에서 동시에 플레이하면 **나중에 저장한 쪽**이 남고, 다른 쪽은 '불러오기'로 맞춰야 합니다(자동 병합 없음 — 데이터 손실을 막기 위한 의도).
- `tools/mobile-frame.html` 은 390×844 뷰포트로 앱을 띄우는 미리보기 페이지입니다 (https://hyosungkwon.github.io/land-rpg/tools/mobile-frame.html?tab=land).
