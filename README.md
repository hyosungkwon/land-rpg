# ⚔️ 영지 RPG — 게스트 전용 통합 부동산 RPG (v3.0.4)

로그인 없이 **바로 시작**하는 모바일 세로형 방치형 RPG + 전국 부동산 게임입니다.
사냥과 부동산이 **골드 하나**로 이어지는 단일 경제로, 별도 환전·이중 연동 없이 한 화면에서 돌아갑니다.

- 라이브: https://hyosungkwon.github.io/land-rpg/
- 저장: `localStorage` (`land_rpg_unified_v3`) · 계정/서버 없음 · 오프라인 동작 (PWA)
- 390×844 기준 모바일 레이아웃

## 1. v3에서 달라진 점

| 항목 | v2.1 | v3.0 |
|---|---|---|
| 로그인 | Google 로그인 + Firebase RTDB | **없음 (게스트 전용)** |
| 첫 화면 | 로그인/연동 배지, 부동산 계정 연결 | 즉시 Lv.1 · 스테이지 1 · 💰500 |
| 화폐 | RPG 골드 / 부동산 현금(₩) 분리 + 환전 한도 | **골드(💰) 하나** |
| 부동산 | 원격 계정의 현금으로 매수 | 사냥 골드로 매수 (같은 지갑) |
| 저장 키 | `land_rpg_state_v1` | `land_rpg_unified_v3` (구버전 자동 초기화) |
| 탭 | 사냥/장비/부동산/랭킹·설정 | 사냥/장비/**부동산**/**설정** |

## 2. 실행

```bash
# 로컬
python3 -m http.server 8080      # 이 폴더에서
# 브라우저: http://localhost:8080

# 검증 (node 불필요, Python + quickjs)
python3 tools/verify_v3.py        # 문법/정적/단위/밸런스 47개 검사
python3 tools/balance_sim.py --hours 2   # 플레이 스타일별 밸런스 리포트
```

`tools/` 는 대부분 `.gitignore` 대상이지만, `verify_v3.py`·`balance_sim.py` 는 재현을 위해 저장소에 포함했습니다. 배포물은 `index.html`, `app.js`, `src/`, `style.css`, `sw.js`, `assets/`, `icons/`, `manifest.json` 뿐입니다.

### 매물 가격 (골드/평)

원본 korea-land 시세를 RPG 골드 스케일로 압축했습니다 (`land.js`의 `priceScale`, `tierPriceMults`).

| 구분 | 가격대 | 회수(임대) |
|---|---|---|
| 군(郡) | 120 ~ 2,000 | 67분 |
| 시(市) | 1,700 ~ 42,800 | 100분 |
| 구(區) | 7,200 ~ 200,000 (강남 200,000) | 143분 |

- 임대수익 = 매물 가치의 분당 1% × 지역 배율 → **접속 중 100%, 앱을 닫아둔 동안 5%**(최대 12시간)
- 거래세 0.3%, 시세는 일일 기준가 ±8% / 장중 ±12% (지역 특성에 따라 확대), 일일 밴드 ±30%
- 한 지역 지분이 커질수록 평당 수익이 줄어드는 원작 규칙 유지

### 건물주 영구 버프 (`src/data.js` `PROP_BUFFS`)

| 버프 | 조건 | 상한 |
|---|---|---|
| 공격력 | 3평 이상 보유한 지역 1곳당 +1.5% | +60% |
| 골드 획득 | 매물 평가액 3,000골드당 +1% | +60% |
| 최대 체력 | 보유 50평당 +1% | +50% |
| 치명타 | 건물 2곳당 +0.2% | +10% |
| 드롭률 | 보유 500평당 +1% | +40% |

매수/매도 즉시 `calcStats`에 반영됩니다.

### 강화석 시세

골드 → 강화석 구매 가격은 **현재 스테이지 몬스터 3마리분 골드**로 따라 올라갑니다(최소 40골드).
임대수익으로 모은 골드를 장비 성장으로 바꾸는 통로입니다.

## 5. 밸런스 (시뮬레이션 검증)

`python3 tools/balance_sim.py --hours 2` — 실제 게임 코드를 QuickJS로 돌린 결과:

| 플레이 스타일 | 5분 | 10분 | 30분 | 60분 | 2시간 |
|---|---|---|---|---|---|
| 적극(강화+부동산+임대) | S9 | S16 | S26 | S28 | **S28** |
| 장비만 | S9 | S16 | S25 | S25 | S25 |
| 부동산만 | S8 | S13 | S22 | S23 | S23 |
| 방치(아무것도 안 함) | S8 | S13 | S20 | S21 | **S21** |

- 1~10스테이지: 30~40초/스테이지로 쾌적하게 통과 (첫 매물은 시작 1분 안쪽에 매수 가능)
- 10스테이지 이후: 몬스터 체력 성장(×1.245, 10스테이지부터 추가 보정)이 가팔라져
  장비 강화 + 건물주 버프 없이는 보스(60초 제한)에서 막힙니다. 방치 플레이는 S21에서 정체.
- 보스 HP ×3.6 / 공격 ×1.15, 60초 제한 — 적극 플레이는 S21까지 보스 실패 없이 통과하고,
  S28 부근에서 성장이 필요해집니다.
- 오프라인 정산: 최대 12시간, 사냥 보상 50% + 임대수익 5%

## 7. 알려진 한계

- 계정/클라우드 저장이 없으므로 브라우저 데이터를 지우면 진행도가 사라집니다(게스트 전용 설계).

- 랭킹은 서버가 없어 제거했습니다(내 기록만 표시).
- `tools/mobile-frame.html` 은 390×844 미리보기용 로컬 도구입니다(배포물 아님).
