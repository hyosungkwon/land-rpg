# 🌟 유아의 놀이터 (`kids-app/`)

7세 아이가 폰에서 바로 켜서 노는 놀이 앱입니다. 설치 없이 링크만 누르면 됩니다.

- 놀이 링크: **https://hyosungkwon.github.io/land-rpg/kids-app/**
- 모바일 미리보기(390×844): `preview.html`
- 예전 `../yua-draw/` 주소는 이 앱의 **그림 놀이** 화면(`?screen=ydraw`)으로 안내합니다.

## 자주 쓰는 작업

```bash
# 자산을 고친 뒤 (주소 해시를 새로 붙인다)
python3 kids-app/tools/stamp.py

# git 커밋/푸시 → GitHub Pages 자동 배포
git add -A && git commit -m "..." && git push origin main
```

- **세이브**: `localStorage` 의 `kidsapp4` 하나. 예전 kids-app 저장본과 그대로 호환됩니다.
- **그림 갤러리/설정**: 그림 놀이는 예전과 같이 `yua-draw-gallery-v1`, `yua-draw-prefs-v1` 을 씁니다.
- **보상**: `App.earnReward(이모지, 문구)` → 스티커 + 캐릭터 경험치. 스티커가 필요 없는 안내는 `App.showTip`.
- **자체 점검 손잡이**(화면에는 영향 없음): `Puzzle`, `Memory._qa()`, `Balloon._qa()`, `DiffGame._qa()`,
  `Maze._qa()`/`_grid()`/`_drag(x,y)`, `Piano._qa()`, `Coloring._qa()`, `Clock._qa()`, `Word._qa()`,
  `Dict._qa()`, `Addq._qa()`, `Mission._qa()`, `Life._qa()`, 그림 놀이는 `window.__yua`.
  화면에서 난 JS 오류는 `window.__errs` 배열에 쌓입니다(index.html 맨 위 수집기).

## 2026-11-26 1단계 — 친구 교감·키우기

- 홈 히어로의 친구를 **톡톡 누르면** 통통 튀고 하트·별이 터지며, 유아 눈높이 말풍선 대사가
  랜덤으로 나옵니다(배고플 때·심심할 때는 상황별 대사). 소리가 켜져 있으면 TTS로도 살짝 읽어 줍니다
  (앞 말을 끊고 읽으므로 겹치지 않음). 홈 상단 🔊/🔇 버튼으로 끌 수 있습니다.
- 히어로 아래 **1줄 컴팩트 교감 바**: 이름(✏️) · 🍎 배부름 게이지 · 💖 친밀도 게이지 ·
  `🍎 간식 주기` · `💖 쓰다듬기` 버튼.
- **간식**: 하루 무료 3개가 자동으로 채워지고, 낚시에서 물고기를 잡을 때마다 1개씩 늘어납니다
  (최대 99개). 주면 배부름 +25 · 친밀도 +8 · **캐릭터 경험치 +1**(스티커는 그대로 → 레벨업 팝업도 뜸).
- **쓰다듬기**: 친밀도 +6, 하트 파티클. 캐릭터 탭은 2.6초에 한 번만 +2.
- **시간이 지나면** 1시간에 배부름 -2.5 · 친밀도 -1.2씩 천천히 내려갑니다(최대 3일치).
- **이름 짓기**: 기본 `꼬마친구`, 10글자까지. 교감 바 이름·🏠 내 방의 `내 친구` 카드·홈 미니 프로필에서
  바꿀 수 있고, 바꾼 이름은 홈 미니 프로필에도 바로 보입니다.
- **저장(save) 새 필드** — 예전 `kidsapp4` 저장본은 그대로 호환됩니다(없으면 기본값):
  `petName` `petHunger`(배부름 0~100) `petHappy`(친밀도 0~100) `petTreats`(간식 재고)
  `petTreatDate` `petTickAt` `petFed` `petPets` `petSound`.
- 자체 점검: `Pet._qa()` 로 이름·게이지·간식·먹인 횟수를 확인할 수 있습니다.

## 2026-11-26 2단계 — 오늘의 미션 · 예비 초1 학습 확장

### 🎯 오늘의 미션(일일 퀘스트)
- 홈 히어로·교감 바 아래 **미니 바**에 오늘 미션 3개 이모지와 `n/3 완료`가 보입니다. 누르면 목록 팝업.
- 날짜(`misDate`)가 바뀌면 **놀이 4갈래(창작·학습·놀이·교감) 중 3갈래**에서 미션 3개를 새로 뽑습니다
  (날짜로만 난수를 만들어, 같은 날 새로 열어도 같은 미션이 나옵니다).
- 목록의 `바로가기`는 그 게임을 바로 열어 줍니다(간식 주기는 홈으로 가서 바로 먹입니다).
- **미션 1개 = 경험치 +1 · 간식 +1**(상단 토스트로 알림). **3개 모두 = 스티커 +2 · 경험치 +3 · 축하 폭죽**.
- 진행도는 각 게임의 성공 지점에서 `Mission.add('이벤트')` 로 쌓입니다:
  `draw`(그림 내기) `color`(색칠 저장) `piano`(동요 완주) `math`(수학 카드 넘기기·빠른 덧셈 정답)
  `clock`(시계 정답) `word`(단어 정답) `dict`(받아쓰기 정답) `ox`(생활 상식 정답) `memory` `puzzle`
  `maze` `diff` `fish`(1마리) `balloon`(60점) `feed`(간식 주기).
- 저장 필드: `misDate` `misSel` `misProg` `misDone` `misClaimed` `misTotal` `misDays` (예전 저장본은 기본값으로 채워짐).

### 🕐 시계 읽기 확장
- 난이도 선택: **😊 쉬움(정시·30분)** / **🔥 도전(5·10분 단위 — 모든 5분)**. 고른 난이도는 저장(`clockDiff`)됩니다.
- 시침은 **파랗고 짧게**, 분침은 **빨갛고 길게** 그려 한눈에 구분되고, 아래 범례가 색을 알려 줍니다.
  도전 난이도에서는 시계 안쪽에 5·10·…·55 분 숫자를 작게 표시합니다.
- 문제가 나올 때마다 TTS로 “몇 시 몇 분일까요?”를 읽어 주고, `🔊 문제 듣기`로 다시 들을 수 있습니다.

### 📝 한글 단어·받아쓰기 보강
- 단어 퀴즈·받아쓰기에 **가족·학교·자연·생활용품** 카테고리를 추가했습니다(단어 퀴즈 8갈래 80단어).
- 두 놀이 모두 **자음·모음/받침 힌트**(`🧩 초성 ㄱ ㅇ ㅇ · 받침 ㅇ`)를 보여 줍니다 — 한글 음절을 초성·종성으로 풀어 표시.

### 🧠 생활·상식 퀴즈(새 학습 카드)
- 학습 탭 `🧠 생활 상식` 카드. 안전·생활·자연·동물 상식 **28문항 OX·4지선다** 중 10문제를 뽑아 냅니다.
- 정답이면 해설을 읽어 주고(TTS), 한 판을 마치면 스티커·경험치 보상. 정답은 오늘 미션(`ox`)에도 쌓입니다.

## 2026-11-26 3단계 — 🖼️ 내 작품 전시관 · ⏰ 사용 타이머(부모 기능)

### 🖼️ 내 작품 전시관 (통합 앨범)
- `창작` 탭 맨 위 **🖼️ 내 작품 전시관** 카드(전폭)와 그림 놀이 화면의 🖼️ 버튼으로 열립니다.
- **그림 놀이 작품**(주제 일치율·자유 그림)과 **색칠하기 작품**이 한 앨범에 날짜 순으로 모입니다.
  위쪽 탭 `전체 / 🎨 그림 / 🖍️ 색칠`로 골라 볼 수 있습니다(각 개수 표시).
- 작품을 누르면 **크게 보기** → `💾 PNG 저장` · `🗑️ 지우기`(한 번 더 확인) · `✕` 닫기.
- 저장 위치는 예전 그대로입니다: 그림 놀이 `yua-draw-gallery-v1`(최근 18장),
  색칠하기 `kidsapp-color-gallery-v1`(최근 24장). 기존에 모은 그림도 그대로 전시관에 나옵니다.
- 색칠하기는 `💾 저장!`을 누르면 PNG 내려받기와 함께 전시관에도 자동으로 담깁니다.
  자유 그림은 `💾 그림 저장`을 누를 때 한 번 담깁니다(같은 그림을 여러 번 저장해도 한 장).

### ⏰ 사용 시간 타이머 · 👨‍👩‍👧 부모님 메뉴
- 홈 상단 바 `👨‍👩‍👧 부모님`·`⏰` 칩을 누르면 **부모님 메뉴**가 열립니다(홈 어디서든 두 번 탭).
- 타이머: **해제 / 10분 / 15분 / 20분 / 30분**. 앱을 보고 노는 동안에만 줄어들고, 남은 시간이
  상단 칩(`⏰ 12:34 남음`)에 보입니다. 1분 이하가 되면 칩이 천천히 깜박입니다.
- 시간이 다 되면 화면을 막는 대신 **😴 졸린 친구**가 나와
  “오늘 신나게 놀았다~ 잠깐 눈 쉬고 나중에 또 놀자!” 하고 부드럽게 알려 줍니다(말로도 읽어 줌).
- 쉬는 화면 아래 **👨‍👩‍👧 부모님이에요** → **곱셈 한 문제**(예: 7 × 8)를 맞히면 메뉴가 열려
  끄거나 늘릴 수 있습니다. 끄기·늘리기는 언제나 이 확인을 거칩니다(줄이거나 처음 거는 것은 그대로).
- 같은 메뉴에 **📊 오늘의 놀이 요약**: 🔢 학습 문제 수 · 🖼️ 그린 작품 수 · 🎯 오늘 미션 n/3 ·
  ⏱ 놀이 시간(분), 그리고 놀이·간식 횟수, 스티커(전체), 친구 배부름·친밀도.
- 저장 필드(kidsapp4, 예전 저장본은 기본값으로 채워짐):
  `timerMin` `timerLeftMs` `timerSetAt` `dayDate` `dayEv` `dayMs`
- 자체 점검: `Parent._qa()` (타이머·남은 초·쉬는 중 여부·오늘 요약), `Parent.test(5)` (5초 타이머로 만료 확인),
  `Exhibit._qa()` (앨범 개수·오늘 담은 수·보고 있는 작품).
