# 🎨 yua-draw — 유아의 그림 놀이

7세 아이가 폰에서 바로 켜서 놀 수 있는 **그림 그리기 + 일치율 점수** 놀이입니다.
설치 없이 링크만 누르면 됩니다.

- 놀이 링크: **https://hyosungkwon.github.io/land-rpg/yua-draw/**
- 키즈 놀이터(같은 폴더의 `../kids-app/`): 홈 → `🎨 창작` 탭 → **그림 놀이 (일치율)** 카드로 이 앱에 바로 들어옵니다.
- 모바일(390×844) 미리보기: `preview.html`
- 자체 점검 페이지: `qa.html?s=trace|rough|scribble|each|shapes|tools|demo|blank`
  - `each` — 26개 주제를 가이드대로 따라 그려 점수 확인
  - `scribble` — 낙서로 제출했을 때 점수가 낮게 나오는지 확인 (`&mode=corner` 구석 낙서)
  - `tools` — 무지개·네온·반짝이·스탬프·채우기·도화지 색·되돌리기 동작 확인
  - `shapes` — 26개 주제의 점선 밑그림을 한눈에 확인

## 놀이 방법

1. 위쪽에 오늘의 주제(이모지 + 한글)가 나옵니다. `다른 주제` 로 바꿀 수 있어요.
2. `힌트` 를 켜면 캔버스에 아주 연한 점선 밑그림이 나타납니다. 따라 그리면 쉬워요.
3. `다 그렸어요!` → 일치율(%)·별 1~3개·칭찬 문구·빠진 부분 힌트가 나옵니다.
   - `그림 저장` : 도화지 색까지 합친 PNG 파일로 저장
   - `다음 주제` : 바로 다음 주제로
4. 오른쪽 위 🖼️ : 최근 12개 그림 갤러리(localStorage)

## 그리기 도구

### 색 20가지 (두 줄 × 10칸)
검정 · 회색 · 연회색 · 흰색 · 빨강 · 주황 · 노랑 · 연두 · 초록 · 하늘 ·
파랑 · 남색 · 보라 · 연보라 · 분홍 · 연분홍 · 청록 · 민트 · 갈색 · 살구

### 붓·도구 7가지
| 도구 | 하는 일 |
| --- | --- |
| ✏️ 크레파스 | 둥글고 선명한 기본 선 |
| 🌈 무지개 붓 | 그을수록 색이 무지개빛으로 부드럽게 흐르는 선 |
| 🌟 네온 붓 | 형광 빛번짐(`shadowBlur`)이 번지는 반짝이는 선 |
| ✨ 반짝이 | 별·작은 반짝이 입자가 톡톡 뿌려지는 스프레이 선 |
| 🪣 채우기 | 탭한 닫힌 영역을 고른 색으로 한 번에 (Flood Fill) |
| ⭐ 스탬프 | ⭐ ❤️ 🌟 🌈 🌸 🦋 🐱 🐶 🌙 ☀️ 🍎 🎈 중 골라 톡톡 찍기 |
| 🧹 지우개 | 그린 곳만 지우기 (도화지 색은 그대로) |

### 도화지 색 6가지
흰색 · 크림 · 연초록 · 연하늘 · 연분홍 · 밤하늘

- 도화지는 **배경 레이어**로 분리되어 있어, 색을 바꿔도 그림이 지워지지 않습니다.
- 채점은 배경색의 영향을 받지 않고 **아이가 그은 선만** 봅니다.
- 저장할 때는 배경색 + 그림을 합쳐 한 장으로 만듭니다.

### 굵기 4단계
가늘게(5) · 보통(10) · 굵게(18) · 아주 굵게(30)

## 채점 방식 (app.js `computeScore`)

1. 아이가 **그은 획(크레파스·무지개·네온·반짝이)** 만 모아 그림 영역(bounding box)을 잰다.
   채우기·스탬프는 모양 채점에서 빼서, 색칠을 많이 해도 점수가 흔들리지 않는다.
2. 그림 영역을 참조 도형 크기에 맞춰 정규화 (가로·세로 축별)
3. **재현율** — 참조 도형을 얼마나 덮었는가 (거리장 기반)
4. **정밀도** — 그은 선이 참조 도형에서 얼마나 벗어났는가
5. **낙서 감지** — 참조에서 멀리 떨어진 획(junk)과 획의 양이 지나치게 많은 경우 감점
6. **특징 비율**(가로세로) + **색 충실도**(고른 색이 주제와 맞는가, 색 계열까지 인정)
7. 위 값을 55~99% 로 부드럽게 펴서 보여줍니다 (`RAW_TO_PCT`).
   가이드대로 그으면 95~98%, 서툰 그림 80%대, 낙서 56~66%.
