# 🎨 yua-draw — 유아의 그림 놀이

7세 아이가 폰에서 바로 켜서 놀 수 있는 **그림 그리기 + 일치율 점수** 놀이입니다.
설치 없이 링크만 누르면 됩니다.

- 놀이 링크: **https://hyosungkwon.github.io/land-rpg/yua-draw/**
- 모바일(390×844) 미리보기: `preview.html`
- 자체 점검 페이지: `qa.html?s=trace|rough|scribble|each|shapes|demo|blank`
  - `each` — 26개 주제를 가이드대로 따라 그려 점수 확인
  - `scribble` — 낙서로 제출했을 때 점수가 낮게 나오는지 확인 (`&mode=corner` 구석 낙서)
  - `shapes` — 26개 주제의 점선 밑그림을 한눈에 확인

## 놀이 방법

1. 위쪽에 오늘의 주제(이모지 + 한글)가 나옵니다. `다른 주제` 로 바꿀 수 있어요.
2. `힌트 보기` 를 켜면 캔버스에 아주 연한 점선 밑그림이 나타납니다. 따라 그리면 쉬워요.
3. 색 10가지 · 굵기 3단계 · 지우개 · 되돌리기 · 싹 지우기(한 번 더 누르면 지워짐)
4. `다 그렸어요! 제출` → 일치율(%)·별 1~3개·칭찬 문구·빠진 부분 힌트가 나옵니다.
   - `그림 저장` : PNG 파일로 저장
   - `다음 주제` : 바로 다음 주제로
5. 오른쪽 위 🖼️ : 최근 12개 그림 갤러리(localStorage)

## 채점 방식 (app.js `computeScore`)

1. 그림 영역(bounding box)을 참조 도형 크기에 맞춰 정규화 (가로·세로 축별)
2. **재현율** — 참조 도형을 얼마나 덮었는가 (거리장 기반)
3. **정밀도** — 그은 획의 중심선이 참조 도형에서 얼마나 벗어났는가
4. **낙서 감지** — 참조에서 멀리 떨어진 획(junk)과 획의 양이 지나치게 많은 경우 감점
5. **특징 비율** (가로세로 비율) + **색 충실도**
6. 위 값을 55~99% 로 부드럽게 펴서 보여줍니다 (`RAW_TO_PCT`).
   가이드대로 그으면 95~98%, 서툰 그림 80%대, 낙서 56~66%.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` / `style.css` | 화면 (모바일 세로형) |
| `topics.js` | 26개 주제와 참조 도형(0~100 좌표계) |
| `app.js` | 캔버스 그리기 · 힌트 · 채점 · 결과 · 갤러리 |
| `sw.js` | yua-draw 전용 서비스워커(네트워크 우선, 오프라인 대비) |
| `preview.html` | 390×844 액자 미리보기 |
| `qa.html` | 자동 점검(따라 그리기·낙서·전 주제) |

> 자산을 고치면 `index.html` 의 `?v=` 숫자와 `sw.js` 의 `CORE` 를 함께 올려 주세요.
