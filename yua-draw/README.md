# 🎨 yua-draw → 🌟 유아의 놀이터 (통합됨)

2026-11-26 부로 이 폴더의 그림 놀이 앱은 **`kids-app/`(🌟 유아의 놀이터)** 안으로 통합되었습니다.

- 놀이 링크(통합): **https://hyosungkwon.github.io/land-rpg/kids-app/**
  - 홈 → `🎨 창작` 탭 → **그림 놀이 (자유 그리기 · 주제 일치율)**
  - 예전 주소로 들어오면 자동으로 `../kids-app/?screen=ydraw` 로 이동합니다.
- 그림 놀이 화면에서 상단 토글로 **✏️ 자유 그리기**와 **🎯 주제 도전(일치율)** 을 오갈 수 있어요.
- 20색 팔레트 · 붓 7종(크레파스/무지개/네온/반짝이/채우기/스탬프/지우개) · 도화지 6종 · 굵기 4단
  · 되돌리기 · 갤러리 · PNG 저장은 그대로입니다.
- 주제 도전에서 **일치율 70% 이상**이거나 **그림을 저장**하면 놀이터의 **스티커 + 캐릭터 경험치**를 받아요.
- 이전에 모은 그림 갤러리(`yua-draw-gallery-v1`)와 설정(`yua-draw-prefs-v1`)은 같은 브라우저에서 그대로 이어집니다.

## 이 폴더에 남은 것

| 파일 | 설명 |
| --- | --- |
| `index.html` | 통합 앱으로 보내는 안내/이동 페이지 |
| `sw.js` | 남은 `yua-draw-*` 캐시를 지우고 스스로 등록 해제하는 서비스워커 |

옛 코드(`app.js`, `topics.js`, `style.css`, `qa.html`, `preview.html`)는 git 기록에 남아 있고,
지금은 `kids-app/js/draw.js` · `kids-app/js/topics.js` · `kids-app/style.css` 로 옮겨져 관리됩니다.

> `land-rpg` 본체 파일(`index.html`, `src/*`, `sw.js`)과는 서로 건드리지 않습니다.
